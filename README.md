# Library Management System

A Java-based **Library Management System** developed to demonstrate the implementation of core **Object-Oriented Programming (OOP)** concepts and data structures.

The project provides a basic structure for managing books and students in a library environment.

## 📌 About the Project

The **Library Management System** is a console-based Java project designed to represent common library operations using Java classes and objects.

The project focuses on:

- Object-Oriented Programming
- Class and object design
- Book management
- Student management
- Stack data structure
- Java programming fundamentals
- Basic library operations

## ✨ Features

- 📚 Book management
- 👨‍🎓 Student management
- 📖 Store and manage book records
- 👤 Store and manage student records
- 📦 Stack-based implementation
- 🧩 Object-oriented class structure
- ☕ Developed completely using Java

## 🛠️ Technologies Used

| Technology | Purpose |

| Java | Application development |
